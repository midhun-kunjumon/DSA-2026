# Pour Decisions — Beer Servings Regression App

A Flask app that estimates `total_litres_of_pure_alcohol` from a country, three servings counts and a continent. Model exploration, comparison, tuning and selection are documented in the executed `model_selection.ipynb` notebook. The trained preprocessing and regression pipeline is saved with pickle in `model.pkl` and loaded by `model.py`.

## Run locally (Windows PowerShell)

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
jupyter notebook model_selection.ipynb
```

The notebook cells already contain their outputs. Rerun the notebook from top to bottom to repeat training and refresh `model.pkl` and the infographic in `static/dataset_overview.png`.

Start the website from the project directory:

```powershell
python app.py
```

Open <http://127.0.0.1:5000>. The landing page includes dataset summaries and charts computed from the CSV; the form accepts the three servings values and country/continent dropdowns.

## PythonAnywhere deployment

1. Upload the project files to a directory such as `/home/yourusername/beer-servings-flask`. Include `app.py`, `model.py`, `model.pkl`, `beer-servings.csv`, `requirements.txt`, `templates/`, and `static/`. Do not upload `.venv/`.
2. In a PythonAnywhere Bash console, create a virtual environment using a Python version supported by your account, then install dependencies:

   ```bash
   mkvirtualenv --python=/usr/bin/python3.11 beer-servings
   pip install -r /home/yourusername/beer-servings-flask/requirements.txt
   ```

   Set the Web app's virtualenv field to that environment. Keep the Python version compatible with the scikit-learn version used to create `model.pkl`; if training under a different Python/scikit-learn version, rerun the notebook in the deployment environment and replace the pickle and chart.
3. In the Web tab, point the WSGI configuration file at the project’s `pythonanywhere_wsgi.py`. Edit its `project_home` value to your actual project path.
4. Reload the web app in PythonAnywhere and check the public page and prediction form.

Pickle files should only be loaded from sources you trust. The submitted `model.pkl` is generated by the included notebook from the included dataset.
